# Smart symptom check — evaluation results

Generated by `python -m ml.evaluate`. Model: `RandomForestClassifier` (300 trees),
122 symptom columns, 49 illnesses.

> **The data is synthetic.** Symptoms and illnesses come from DDXPlus (Fansi Tchango et al.,
> NeurIPS 2022, CC-BY), a dataset of *simulated* patients generated from a medical knowledge base.
> These figures say how well the model reproduces that generator. They are **not** evidence of
> accuracy on real patients, and the tool must not be used for diagnosis.

Each test row is a full DDXPlus questionnaire (every symptom answered yes or no).

## 2. Whole pipeline on typed descriptions

300 descriptions written from random test rows, each naming 3 of the row's symptoms by label
(e.g. "swollen lymph nodes, headache and weight loss"), run through text matching → red flags → Random Forest.
Users type a few symptoms, not a 122-item questionnaire, so this is much harder than section 1.

Statuses: ok 205, emergency 65, low_confidence 30.

| Method | Correct department | Accuracy |
| --- | --- | --- |
| Smart check only (non-ok counted as wrong; emergency = Emergency Medicine) | 208/300 | 69.3% |
| As shipped (non-ok → keyword checker) | 212/300 | 70.7% |
| Old keyword checker | 45/300 | 15.0% |
| Smart check, "ok" results only | 188/205 | 91.7% |

On "ok" results the true illness is in the top three 99.0% of the time. Follow-up
questions (information gain) are not used here; each description is a single request.

## 5. Data

| | Training split | Test split |
| --- | --- | --- |
| Source file | `release_validate_patients` (see note) | `release_test_patients` |
| Rows after removing duplicates and capping per illness | 15619 | 15686 |
| Rows per illness (min / median / max) | 1 / 112 / 2000 | 1 / 114 / 2000 |

- Columns: the 122 DDXPlus symptoms (no history items, no demographics); categorical and
  multi-choice answers collapsed to present/absent (absent = the evidence's default value).
- **Training used the DDXPlus validation split** because `release_train_patients` was not available.
  When it is, rerun `python -m ml.ddxplus_adapter --split train` and `python -m ml.train_model`.
- Removing duplicates leaves few distinct patterns for some illnesses (as few as 1),
  so the per-illness cap cannot make the classes balanced.
- Follow-up details always present with their parent question are filled in with it at
  prediction time: E_54 → E_53, E_55 → E_53, E_56 → E_53, E_130 → E_129, E_133 → E_129, E_152 → E_151.
- Pain location is also split into 12 body-region columns (headache, chest pain,
  stomach pain...; `PAIN_REGIONS` in `ml/ddxplus_adapter.py`), so typed pain keeps its location.
- "pain" is filled in for symptoms that come with it in nearly every training row
  (DDXPlus asks it as a gate question): able to pass stools or gas, allergen exposure, bloating, chest pain at rest, chills, choking sensation, early fullness, extreme tiredness, fear of dying, feeling detached, general malaise, green or yellow nasal discharge, losing weight or appetite, loss of consciousness, loss of smell, mouth ulcers, pain relieved by leaning forward, pain worse with coughing or straining, red eyes, seizure, sweating, swelling, swollen lymph nodes, symptoms worsening over 2 weeks, vaginal discharge, vomiting blood, waking up breathless.

## 6. Items that need review

- **Department map** (`ml/data/disease_dept.json`) is provisional, in particular:
  Unstable angina: Could be Emergency Medicine: unstable angina can precede a heart attack.; Inguinal hernia: The app has no general surgery department; General Medicine is a first point of contact.; SLE: No rheumatology department; General Medicine chosen.; Anemia: No haematology department; General Medicine chosen.; Chagas: Infectious, with cardiac complications; could be Cardiology.; Whooping cough: Could be Pediatrics for children.; Acute dystonic reactions: Often presents to Emergency Medicine.; Viral pharyngitis: Could be ENT.; Scombroid food poisoning: Could be Emergency Medicine when severe..
- **Red-flag rules** (`ml/red_flags.py`) and **symptom labels** (`ml/data/ddxplus_labels.json`).
- **Synonyms** (`ml/data/symptom_synonyms.json`): machine-drafted, every entry marked "needs review";
  Nepali and Romanised Nepali phrases still to be added.
- Confidence threshold 40% (`MIN_DEPARTMENT_PROBABILITY`) and minimum
  of 3 symptoms (`MIN_SYMPTOMS`) in `ml/symptom_model.py`.
- TOPSIS weights and the assumed 30 minutes per appointment.
